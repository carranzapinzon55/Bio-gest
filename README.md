# Bio-gest
BIO-GEST es un proyecto de E-comerce para Tenebrios Gold, una empresa dedicada a la venta de alimentos vivos para animales. La plataforma busca facilitar la compra de productos como tenebrios, zophobas y cucarachas Dubia, permitiendo gestionar el catálogo, pedidos, inventario, promociones y atención al cliente desde un solo sistema.
